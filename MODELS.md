# Agents and model backends

This list will go stale; the protocol will not.（这份清单会过时，协议不会。）

“Verified” below means the linked official documentation was checked, not that a paid request succeeded. All real backend integrations are **untested / 未测试** in this repository; the runner's local tests use fake agents. A compatible API is a transport contract, not evidence of identical behavior, billing, or permissions. Dates apply to the specific claims beside each source.

## Custom adapters

`DELEGATE_CMD` receives the prompt on stdin in the target directory. Its wrapper must write **only the final message** to the absolute file named by `DELEGATE_OUT`, keep progress on stdout/stderr (the runner captures both), and exit nonzero on provider or tool errors. This repository supplies no separate adapter files; the command references above establish syntax, not an integration test.

MiniMax Code's documented input and final-message flags fit the contract directly: `export DELEGATE_CMD='mcode exec --input - -o "$DELEGATE_OUT"'`, then run with `--agent custom`. Authenticate/configure `mcode` separately. This recipe is **未测试** against a live account. [Official headless flags](https://agent.minimaxi.com/docs/cli/automation). 核实日期 2026-10-08.

## 各家差异要注意什么 / Differences that matter

| Concern | Practical consequence and official evidence | Verification |
| --- | --- | --- |
| Instruction following | No official source establishes a cross-provider ranking for obeying a 15-line summary, nor is transport compatibility such a guarantee. Put the report format in the brief, cap returned bytes, and verify acceptance yourself. **未找到官方依据** for a comparative ranking; structured output is a separate CLI capability. [Gemini headless formats](https://geminicli.com/docs/cli/headless/), [Qwen output formats](https://qwenlm.github.io/qwen-code-docs/en/users/features/headless/). | 核实日期 2026-10-08 |
| Tool-call stability | No comparative reliability ranking was verified. Check support for tool schemas, thinking blocks, tool results, streaming and errors on the exact endpoint/model. DeepSeek and MiniMax publish compatibility limits; partial Anthropic compatibility does not guarantee every Claude Code feature. [DeepSeek compatibility details](https://api-docs.deepseek.com/guides/anthropic_api/), [MiniMax compatibility](https://platform.minimax.io/docs/api-reference/text-anthropic-api). | 核实日期 2026-10-08 |
| Context windows | The selected model, account and CLI compaction threshold all matter. Kimi documents different windows by model/membership; a larger window permits more context but does not remove repeated context reads. Check current limits before changing models or compaction settings. [Kimi model/window table](https://www.kimi.com/code/docs/en/kimi-code/models.html), [MiniMax Claude Code settings](https://platform.minimax.io/docs/m-plan/claude-code). | 核实日期 2026-10-08 |
| Sandbox and networking | Codex uses a configured sandbox; this runner chooses `workspace-write` and disables worker-command networking unless `DELEGATE_CODEX_NETWORK=1`. This does not stop Codex's own model API requests. Gemini has separate sandbox controls. `claude-compat` uses Claude Code's `acceptEdits` permission mode, not the Codex sandbox; Bash permissions depend on Claude Code settings. `custom` inherits its chosen CLI's policy. [Codex security](https://developers.openai.com/codex/security), [Gemini sandbox](https://geminicli.com/docs/cli/sandbox/), [Claude permission modes](https://code.claude.com/docs/en/permission-modes). | 核实日期 2026-10-08 |
| Instruction files | Codex discovers `AGENTS.md`/overrides; Claude Code reads `CLAUDE.md`. Gemini defaults to `GEMINI.md`, Qwen Code to `QWEN.md`, with configurable filenames. Kimi documents global and project `AGENTS.md`. Do not assume a file is read solely because it exists: include critical scope rules in the brief and check each CLI's discovery settings. [Codex](https://developers.openai.com/codex/guides/agents-md), [Claude memory](https://code.claude.com/docs/en/memory), [Gemini](https://geminicli.com/docs/cli/gemini-md/), [Qwen settings](https://qwenlm.github.io/qwen-code-docs/en/users/configuration/settings/), [Kimi agents](https://www.kimi.com/code/docs/en/kimi-code-cli/customization/agents.html). | 核实日期 2026-10-08 |
| Data transfers and compliance / 数据出境与合规 | Hosted inference sends prompts and any code/tool output the agent includes to the provider's servers. Local shell execution and `.delegate/` exclusion do not keep inference local. Provider nationality is not a data-residency guarantee: account, service region, deployment scope and cross-region processing matter. Before sending proprietary code, personal data or secrets, confirm your organization's authorization and the provider's retention/training, residency and contractual terms. No endpoint in this list is certified as compliant for every jurisdiction or workload. [Model Studio regions and deployment scopes](https://help.aliyun.com/en/model-studio/regions), [Kimi regional endpoints](https://www.kimi.com/code/docs/en/kimi-code/models.html), [Gemini CLI privacy and terms](https://geminicli.com/docs/tos-privacy/). | 核实日期 2026-10-08 |

Plan restrictions also matter: Model Studio describes Coding Plan/Token Plan endpoints as intended for interactive coding tools, not backend services. Do not treat a documented Claude Code integration as authorization for arbitrary unattended batch workloads; use the appropriate pay-as-you-go product where required. [Official endpoint and plan restrictions](https://help.aliyun.com/en/model-studio/base-url). 核实日期 2026-10-08.
